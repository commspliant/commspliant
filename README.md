# CommsPliant

### 🛠️ Tools, SDKs & developer infrastructure for compliance communication

CommsPliant builds developer tools and infrastructure for organisations that create, manage, review and deliver structured communications.

Our GitHub projects include **open-source developer tools**, **API SDKs**, integrations and components that can be used independently or as part of CommsPliant.

---

## 🚀 Open Source

### 📝 HTML Editor

A full-featured, extensible HTML document editor for developers.

Designed to provide a **Word-like editing experience for HTML**, with support for rich formatting, tables, images, styles, custom extensions, Markdown conversion, sanitisation and application-defined functionality.
